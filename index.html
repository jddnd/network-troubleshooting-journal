Network Troubleshooting Journal

Technical troubleshooting records organized by three primary classification dimensions: Discipline, Aspect and Platform.

Discipline

Engineering domain in which the troubleshooting activity belongs.

  • Routing
  • Switching
  • Firewall
  • Wireless
  • Identity
  • PKI

Aspect

Specific function, subsystem or behavior being investigated.

  • Client Roaming
  • RF Cell Sizing
  • RRM / TPC
  • Fast Transition (802.11r)
  • 802.1X Authentication
  • EAP-TLS

Platform

Vendor platform or system on which the behavior is implemented or observed.

  • Cisco Catalyst 9800
  • Cisco CW9176I
  • Cisco ISE
  • Windows 11
  • Intel AX211

Classification Method

Documentation rule

Discipline identifies the engineering domain. Aspect identifies the technical behavior being investigated. Platform identifies where that behavior is implemented or observed.

A troubleshooting record may reference multiple supporting disciplines, aspects and platforms, but one primary value is assigned to each dimension for indexing.
